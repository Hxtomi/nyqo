# Nyqo n1 model card

The current model card is maintained in [release/huggingface/README.md](release/huggingface/README.md). It contains the model details, training method, comparison results, limitations, and Transformers loading example, and will serve as the model repository's `README.md` on Hugging Face.

The release target is [Hxtomi/nyqo](https://huggingface.co/Hxtomi/nyqo). Weight upload and a fresh-GPU loading check are still pending.

For the current local-checkpoint workflow, see the [usage guide](docs/usage.md). Earlier evaluation receipts and their original score bounds are preserved in the [evaluation record](docs/results.md) and [evidence directory](evidence/README.md).
