# Nyqo n1 model card

The current model card is maintained in [release/huggingface/README.md](release/huggingface/README.md). It contains the model details, training method, comparison results, limitations, and Transformers loading example, and serves as the model repository's `README.md` on Hugging Face.

The checkpoint files are uploaded to [Hxtomi/nyqo](https://huggingface.co/Hxtomi/nyqo). File integrity and local CPU loading and generation have been checked; a fresh-GPU loading check is still pending.

For the current local-checkpoint workflow, see the [usage guide](docs/usage.md). Earlier evaluation receipts and their original score bounds are preserved in the [evaluation record](docs/results.md) and [evidence directory](evidence/README.md).
